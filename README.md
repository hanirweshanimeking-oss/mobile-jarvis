# Mobile Jarvis

A new Android app project inspired by the MEGHA / Jarvis concept.

## Project structure

- `app/` — Android application module
- `build.gradle.kts` — root Gradle configuration
- `settings.gradle.kts` — project settings
- `gradle.properties` — Gradle configuration

## Run locally

1. Install Android Studio or the Android SDK.
2. Open this folder in Android Studio.
3. Let Gradle sync.
4. Run `app` on an emulator or physical device.

## Included features

- Jetpack Compose UI
- MEGHA assistant identity
- Conversational chat panel
- Voice toggle
- Agent council dashboard
- Memory and task cards
- Dark futuristic "cosmic noir" visual style
